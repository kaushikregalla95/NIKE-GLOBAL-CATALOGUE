# NIKE GLOBAL CATALOGUE – Machine Learning Research Project

## Overview

This repository contains a complete Machine Learning and Data Analytics research project developed using the **Nike Global Catalogue Dataset**. The project focuses on product analytics, pricing prediction, stock availability analysis, clustering, and marketing insights using publication-ready methodologies.

The project includes:
- 7 publication-ready research questions
- Machine Learning models
- Exploratory Data Analysis (EDA)
- Publication-quality figures
- CSV tables
- Kaggle-compatible Jupyter notebooks

---

# Research Questions

## RQ1
How do discounts influence product availability across different product categories?

## RQ2
Can product prices be accurately predicted using product attributes?

## RQ3
Which factors most strongly influence stock availability?

## RQ4
Are there significant differences in pricing strategies across countries?

## RQ5
Can Nike products be clustered into meaningful market segments?

## RQ6
How does gender segmentation affect pricing and discounts?

## RQ7
Can product availability levels be predicted using machine learning?
